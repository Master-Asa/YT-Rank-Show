# 背景收錄使用流程（v0.6.2）

1. 把新版程式放到 OneComme 的 plugins 資料夾下獨立目錄；確認第一層有 plugin.js。不要使用舊的 v0.1.0 ZIP。
2. 在 OneComme 插件視窗重新讀取並啟用 YT Rank Show 一次。啟用狀態由 OneComme 記住，之後隨 OneComme 啟動。新版獨立同步器會安全交接並停止；若仍是 0.3.x 舊同步器占用 11181，先關閉它，再重新啟用插件。
3. 更新使用者：先重新整理「原本有紀錄的管理頁」，保持原瀏覽器、原網址／IP。不要先換成新來源或清除網站資料。頁面會把舊紀錄、鎖定頻道、清空標記、外觀與 OBS 金鑰一次備份移入背景。
4. 確認頁面「背景收錄已啟用」且紀錄／三種月榜一致。若提示不同頻道、資料格式或儲存錯誤，原資料仍保留，先下載備份，不要清空重設。
5. 之後照常開 OneComme、連到直播。固定 /channel/UC… 頻道網址若有可靠的對應直播資訊，可自動確認；直接填影片網址的新場次，Windows 預設會顯示獨立確認小視窗，不需開管理頁。這不會自動接受未核對的其他頻道。
6. 管理頁可以關掉，OBS 每兩秒從背景讀取。關閉 OneComme 或停用插件就不再收錄；重新啟動不會補抓 YouTube 全部歷史，只能收到 OneComme 當下提供的快取與後續事件。

資料與程式分開：Windows `%APPDATA%\YT-Rank-Show\data`。更新只替換程式檔，不碰此資料夾。首次移入沿用原 OBS 金鑰；若 OBS 指向錯誤來源，回原管理頁重新複製，勿把真實紀錄換成測試資料。

「立即同步」用來立即核對背景輸出，不是補抓歷史按鈕。外觀儲存會先寫入背景，再提供 OBS；另一頁已修改外觀時會拒絕舊草稿覆寫。

若 OneComme 顯示啟用但管理頁仍只顯示模板模式，檢查 11181 是否被舊同步器占用；不要同時啟動兩份背景程序。一般使用不需要手動開同步器。

## 新直播確認小視窗

先在管理頁設定要統計的頻道一次，之後使用 OneComme「新增 → 填直播網址 → 連接」。新場次的視窗會顯示統計頻道、直播 ID，以及 OneComme 有提供的標題；這是人工確認，不是線上查證。

- **是，加入統計**：保存場次歸屬，已收到且符合規則的支持紀錄也會計入。之後同一場不再詢問。
- **不是此頻道**：記住這個頻道／場次的略過選擇，不刪除支持紀錄。選錯仍可在管理頁手動加入。
- **稍後或關閉**：本次執行不再重複詢問；未核對事件仍保存，但不計入此頻道。可手動確認，或下次啟動 OneComme 再詢問。

等待回答不會停止背景收錄。若更改頻道、移除連線或關閉提示，舊視窗的回覆不會加入統計。多場連線逐一提示，不同時堆疊。

在「頻道與直播 → 新直播確認小視窗」可關閉提示。視窗由本機 Windows PowerShell／Windows Forms 顯示，不查詢 YouTube、不傳送資料到外部；若 Windows 政策阻擋，管理頁會提示改用手動確認，不會偷偷自動加入。其他作業系統不支援此小視窗。

**OBS 使用整個螢幕擷取時，可能拍到此視窗。** 不保證自動排除擷取；可使用遊戲／指定視窗擷取，或事先關閉確認提示。
