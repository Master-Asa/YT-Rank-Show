# 本機資料與隱私

## 這個版本做什麼

- 背景插件接收 OneComme 提供的 comments、services、meta、meta.clear，不要求帳號密碼、登入憑證、全域 config、語音或其他插件權限。
- 不含分析追蹤、遙測、雲端備份、自動更新下載、CDN、外部圖片／字型載入。外部查詢僅限使用者主動同意後查詢 YouTube 公開頻道或影片資料，並非完全不聯外。
- 歷史匯入的影片查詢只送出清理後的公開影片網址，不送來源紀錄、觀眾、留言或金額。標題與作者取自該影片的公開 metadata，不採用推薦影片或觀眾資訊。匯入核對狀態只在本次預覽有效，重新預覽／重啟後需再查；已查到的標題與頻道資訊另保存於本機，供場次清單辨識；查到不符會阻擋匯入，未知需逐場人工確認。網路查詢不鎖住背景存檔佇列。
- 「查詢頻道」只送出清理後的公開頻道網址；YouTube 與 DNS 服務會收到連線所需資訊，YouTube 可見公用 IP、時間與一般請求標頭。不讀瀏覽器 Cookie、不傳送登入資訊、支持紀錄、外觀、備份或 OBS 金鑰，也不連第三方頻道解析服務。同意只保留本次頁面，不會在啟動或背景收錄自動查詢。
- 查詢使用 HTTPS、限定 www.youtube.com、驗證 DNS 並固定至公開 IPv4，不跟隨重新導向，不執行網頁腳本。10 秒逾時、4 MiB 回應上限、5 秒間隔、同時一筆。網路或 YouTube 格式／驗證限制可能造成失敗；可改用 UC ID 完全離線設定。這些限制降低風險，不代表零風險。
- 管理頁只連這台電腦的 OneComme 和 127.0.0.1:11181。OBS 向 11181 讀取榜單和已選外觀。這些是本機程序之間的傳遞，不是上傳網站。
- 背景收錄直接使用 OneComme 插件事件，不需要管理頁或 OneSDK。尚未啟用背景時保留舊模板的本機 OneSDK 過渡模式，畫面會明確提醒需要保持管理頁開啟。

## 資料存放與包含內容

Windows 背景資料在 `%APPDATA%\YT-Rank-Show\data`，包含事件、觀眾 ID／名稱／留言、直播 ID、金額、會員／寶石數、頻道設定、清空標記、外觀圖片／字型與 OBS 金鑰。TXT 在該資料夾的 output。它不放進 OneComme 可提供靜態網頁的插件目錄。

舊管理頁第一次移入前，會先把來源與背景現況一起備份到同一個私有資料夾；成功後不刪除舊 localStorage／IndexedDB。JSON 下載也包含隔離、測試及已清空統計的原始紀錄。請不要把整個日用資料夾打包分享。

## 本機接口保障與界線

- 11181 僅綁 127.0.0.1，驗證 Host；瀏覽器來源只接受 localhost、loopback 或此電腦實際網卡 IP 的 11180，不接受任意私人網段。
- 管理 API、外觀管理和字型清單要求本機工作階段金鑰。公開的 OneComme 插件 REST 只回啟動狀態，不回傳紀錄或接受設定修改。
- OBS URL 是唯讀能力金鑰；不要公開分享該 URL。背景模式拒絕網頁重新發布、覆寫排行。
- 這不是本機多使用者隔離或加密保險箱。同一 OS 帳戶的惡意程式、同源其他腳本、電腦管理員仍可能讀取檔案或介面；請只安裝信任的 OneComme 插件。
- 使用者自己匯出的 CSS 或備份可能包含背景圖、字型；分享前自行確認資料和授權。OBS 顯示的姓名／數值自然可能出現在直播畫面。

## 不涵蓋的保證

OneComme 自己仍需要連線 YouTube 等平台；我們不能替 OneComme、OBS、其他插件、使用者額外貼入的 CSS 或已受感染的電腦保證完全沒有外連。這也不是「100% 安全」認證。

發布流程使用明確檔案白名單，不包含開發備份、參考插件、日誌或使用者資料。

## 儲存格式 v4

state.json 是小型索引；月份紀錄與外觀位於 objects，保留現行及前一代索引所引用的物件。新版首次轉換會保留 before-storage-v4 備份。backups 內的 gzip 是完整本機快照，不是加密。使用者確認後可整理手動／修復備份，保留最新五份；升級與移入前備份不自動刪除。仍會在記憶體載入全部事件，尚非大型資料庫。
## 歷史匯入與字型名稱

只有使用者按下讀取按鈕，才會唯讀開啟本機 OneComme 的 comments.db，或處理使用者選取的日誌內容。預覽不會寫入支持紀錄；勾選直播、核對頻道並確認後，才先備份、再保存到本插件資料夾。來源資料庫與日誌不會被修改。普通聊天不匯入，支持紀錄中的觀眾名稱／ID、事件時間、金額及留言等資料會保存於本機。

字型清單讀取 Windows 字族、字面、登錄名稱與檔案定位。相容載入僅允許清單已列出的本機 Windows Fonts／使用者 Microsoft\\Windows\\Fonts 資料夾內 TTF／OTF／TTC，單檔最多 32 MB；HTTP 不接受任意路徑，須通過本機來源與工作階段憑證。可見樣張必要時唯讀讀取字型，選用的相容字型資料隨外觀存於本插件私有資料夾，並只提供本機管理頁與持有讀取金鑰的 OBS。分享外觀備份或 CSS 可能包含選用字型，請先核對授權。發行包不含使用者字型。Windows 相容讀取器使用系統元件，不連線外部服務。



## 固定頻道自動確認

僅沿用 OneComme 既有 services／meta 訊息，核對目前連線的固定頻道網址與解析出的直播網址。無法確認歸屬時維持待確認，不以觀眾、連線名稱或登入者資訊猜測。插件不為此新增 YouTube、第三方或雲端請求。
# 場次資訊補充（v0.8.0）

使用者主動查詢的影片標題、頻道與查詢來源可保存在本機頻道設定，供場次清單辨識；不會因此自動加入統計。移出／重新加入只變更本機歸屬與計榜資格，保留原始支持事件。查詢仍只傳公開影片網址與連線 IP，不傳觀眾、金額、外觀或 OBS 金鑰。
