# 幣別與新台幣換算

## 使用方式

SC／Super Sticker 會依「統計與一般設定 → 換算匯率」自動換算成新台幣。欄位代表 **1 單位外幣等於多少新台幣**；新台幣倍率固定為 1。原始金額與幣別仍保留於支持紀錄。

使用的是本機設定匯率，不會背景連網更新匯率，也不是 YouTube 實際結算收入（平台分成、稅費與結算匯率不同）。預設值僅供排行榜估算，使用者可自行修改；匯率日期是使用者記錄設定日期，並非即時報價時間。

優先使用 OneComme 提供的明確幣別；只有金額文字時，可辨識 `RM 10.00`、`MYR 10.00` 或 `10.00 MYR` 等形式。單獨 `$` 沿用設定中的 TWD／USD，不推測為新加坡幣、澳幣或加幣；有明確代碼時優先採代碼。單獨 `¥` 沿用 JPY，若來源明確標示 CNY 則採 CNY。

數字接受來源直接提供的有限數值，或使用小數點與千分位逗號的文字（例如 `1,000.50`）。`Rp 10.000` 這類可能是十、也可能是一萬的文字，需有来源明確金額才換算；不會硬猜本地化千分位或錯誤的逗號小數格式。幣別／金額／匯率無法確認時保留待核對，不計入榜單。

## 升級與重新計算

升級保留既有自訂匯率，補入缺少的新幣別設定。首次啟動時，如果已保存的新增幣別待核對紀錄可辨識，會先建立本機修復快照再補上換算；沒有足夠原始資訊仍維持待核對。

修改匯率並「儲存設定」，或按「重新計算排行」，會依目前設定重新換算已保存的 SC／貼圖。金額變更前先建立修復快照，不更改事件 ID、不新增副本，也不解除排除、清空、測試或頻道歸屬限制。這是統一設定匯率的排行榜，不逐筆回查交易當日匯率。
