# YT Rank Show

線上更新：在「統計與一般設定 → 軟體更新」檢查正式新版；自動檢查預設關閉，不會強制關閉 OneComme 或自動安裝。私人儲存庫尚未公開時無法匿名取得更新；詳見 [線上更新與隔離測試](docs/UPDATES.md)。

OneComme 的 YouTube 支持紀錄與 OBS 排行榜插件。支援 SC／Super Sticker、贈送會員與寶石三種獨立榜單、頻道鎖定、逐場確認、月份 CSV、外觀預覽、自訂榜名、字型與背景圖。

## 適用環境

主要驗證環境：**Windows 11 64 位元（目前為 25H2）＋OneComme 9.1.1**。OBS 需含「瀏覽器」來源。確認小視窗需要系統 Windows PowerShell 5.1 與 Windows Forms；一般安裝不需另裝 Node.js。

Windows 10 尚未完整驗證；**不支援 Windows XP／Vista／7／8／8.1、32 位元 Windows、macOS、Linux 與 Windows ARM**。安全政策或系統元件限制可能使小視窗無法顯示，此時可在管理頁核對，不會自動同意或刪除紀錄。詳見[適用環境、跳窗限制與問題回報](docs/INSTALL.md#適用環境與支援範圍)。

## 管理頁配色與紀錄篩選

管理頁以功能區塊分組：統計頻道、自動追蹤、新直播提醒、手動加入與場次管理。手動加入預設收合；較長的操作規則可展開各區「使用說明／連線方式／提醒方式」。聯外同意、錯誤與刪除確認仍會直接顯示。

右上角「管理頁配色」可選深色、淺色或跟隨系統，首次使用預設深色。選擇只保存在目前瀏覽器，不聯外、不寫入插件備份，也不影響 OBS 榜單或外觀預覽。清除瀏覽器網站資料後會回到預設；其他瀏覽器需各自設定。

「支持紀錄」可依全部狀態、已計入、待核對、不計入篩選；清除篩選可恢復全部顯示。篩選不會刪除紀錄或改變排行榜。已移出、手動排除、測試、已清空與已確認其他頻道等紀錄列為不計入；完整原因仍可在詳情查看。

場次管理保留已加入／未加入頁籤，按最早紀錄日期（台北）分類年份與月份，初次顯示有紀錄的最新月份，每頁最多 20 場。這不是開台時間；無日期的場次可選「日期不明」或「搜尋全部月份」找到。選取場次只開啟資訊欄，不會加入或移出統計；未加入頁籤可再篩選待確認、已略過、已移出或其他頻道。

## 場次加入與移出

「頻道與直播 → 直播場次管理」分為已加入與未加入統計，可搜尋標題或影片 ID。移出只改歸屬與計榜資格，不刪原始紀錄；背景不會自動加回，也不反覆跳窗。重新加入會使用現有有效紀錄重新計算，不重複新增；測試、已清空或其他不合格事件仍不計入。變更前先建立本機備份，備份／存檔失敗不套用。

標題優先使用已收到的本機直播資訊，缺少時可經同意查詢 YouTube 目前公開資訊，結果保存本機。查詢不等於加入；查明屬於其他頻道時不能加入目前頻道。標題缺失時仍保留 ID 供核對。場次資訊與歷史匯入預覽是不同用途，前者管理已保存的統計歸屬，後者才讀取 OneComme 舊紀錄。

## 調整 OBS 外觀

各名次的名稱會自動對齊，包含沒有 emoji 的名次。OBS 外觀預設隱藏名稱開頭的 `@`；如需顯示，可在該榜「內容 → 進階名稱設定」取消勾選。這只改畫面，不改原始紀錄與使用者 ID。

在「OBS 外觀與輸出」的九張卡片選定一張榜，按「設定與預覽」。編輯器分為「內容」「文字與名次」「背景與版面」。選字型後立即預覽；按「儲存並更新這張榜」才同步到 OBS，不影響其他榜。

- 「讀取本機字型」取得字型自身提供的名稱與別名；「搜尋與試看」可用中文或英文搜尋。並非所有字型都有中文名稱或中文字形；缺字會使用備援字型。各欄位指定字型優先於整體字型。名稱載入失敗時，會嘗試唯讀載入本機已安裝的 TTF／OTF／TTC（32 MB 內；TTC 抽取匹配字族的常規字面）。選用的相容字型資料會隨該榜外觀保存，供預覽與 OBS 共用；不會把整份字型清單打包。超額、集合字面無法辨識或格式不相容時仍可失敗；仍允許選取並保存字型名稱，但會提示可能使用替代字型。也可匯入合法授權的 WOFF／WOFF2／TTF／OTF。缺字不等於載入失敗；樣張包含中文、日文及英文以方便辨識。
- 在「文字與名次」展開「前三名 emoji／符號」，每名可輸入或貼上 emoji、文字符號，也能按「使用 🥇／🥈／🥉」。Windows 可按 Win＋. 開啟表情符號。支援只顯示數字、圖示＋數字、只顯示圖示；留白保留數字，第四名以後仍顯示數字。大小使用 em，跟著榜單字級縮放。彩色 emoji 使用系統表情字型，顏色不跟著金銀銅文字色改變；不同系統或 OBS 版本的外觀可能略有不同。
- 舊排名圖片會在啟動時先備份，再轉成對應獎牌 emoji，不再提供排名圖片上傳；背景圖片仍可使用。
- 九張榜完全獨立。不需要重複設定時，先儲存，再用「複製外觀到其他榜」選取目標並確認；只複製一次，保留各目標的榜名與顯示名次，之後修改不會互相連動。舊共用與分期間外觀在首次啟動時先備份，再保留原有效外觀轉入各榜。
- 既有 OBS 網址仍可使用。尚未重新儲存顯示名次時沿用舊網址的 3／5／10 名；儲存後同一張榜的所有網址跟隨該榜設定。請重新整理 OBS 來源以載入新版網頁程式。
- 字型集中去重保存，最多 64 MB；圖片和字型只存本機，不上傳。統計、TXT 與 CSV 不因複製外觀而改動；分享備份／CSS 前請確認圖像及字型授權。

## 每次開台都要確認場次嗎？

首次設定可貼 @頻道網址，勾選同意並按「查詢頻道」。插件只向 YouTube 查公開頻道資料，對方會收到查詢網址與連線 IP；不傳送支持紀錄、外觀或 OBS 金鑰。查到後需核對並確認儲存，不會在啟動或背景收錄自動查詢。網路／YouTube 驗證或頁面格式限制可能導致失敗，仍可填 UC ID 離線設定。

「頻道與直播」會提供已鎖定頻道的固定網址（https://www.youtube.com/channel/UC…）。將它貼入 OneComme 的連線網址，OneComme 解析出目前直播並發布 metadata 後，插件會自動加入對應場次；管理頁可關閉。已收到的待確認支持事件也會依既有規則重新計榜，資料不會重複新增。

直接貼影片網址時，Windows 預設會跳出獨立的直播確認小視窗，選「是，加入統計」即可，不需開管理頁；等待回答時仍保存收到的支持紀錄。「不是此頻道」會記住略過，「稍後」或關閉則本次不再詢問；選錯可在管理頁手動更正。可於「頻道與直播」關閉提示。小視窗可能被 OBS 螢幕擷取拍到，詳見[背景收錄流程](docs/BACKGROUND.md)。

@handle 或來源缺少有效直播 ID 時，仍需在管理頁手動指定。其他頻道不會自動計入，既有不同歸屬也不會被覆蓋。畫面會標示自動確認來源。本場尚無紀錄時，OBS 保留榜名，不沿用上一場名單；關閉「顯示排行榜標題」則隱藏標題。

## 已有 OneComme 舊紀錄可以補入嗎？

匯入前可勾選聯外同意，查詢單支或所選影片（每次最多 10 場）的目前公開標題與頻道。卡片標示「相符／不符／無法確認」，不符的影片不能匯入；未查詢或查不到時須逐場人工確認。查詢不會直接保存紀錄，仍需按匯入並先建立備份。YouTube 標題可能與當年開台標題不同，畫面會另列本機原標題；最早紀錄不是開台時間。

可以。在「頻道與直播」展開「匯入過去直播紀錄」，選擇本機 OneComme 保存紀錄，或自行選取日誌檔，再指定日期範圍、讀取預覽。勾選要加入的場次，確認它們屬於目前鎖定頻道後，按「備份並匯入所選場次」。安裝不會自動匯入，預覽也不會改動紀錄。

會辨識 SC、Super Sticker、贈送會員、受贈會員及寶石；一般聊天不匯入，受贈會員不計入贈送榜。重複事件會去重，測試、衝突及重設限制仍然生效，使用目前設定的匯率換算。匯入前會建立本插件備份，不改動 OneComme 原始資料。

場次標題與開台時間只在來源有提供時顯示；「最早紀錄」不是實際開台時間。每次最多查詢 366 天，日誌最多 30 檔、合計 64 MiB；資料量過大時請縮小日期範圍。支援本機 comments.db 與包含原始事件物件的 JSON 陣列／逐行 JSON 日誌，不支援只有畫面文字的紀錄。沒有保存或已刪除的資料不能補回，也不會上網追抓歷史。

OneComme 8.0 起，保存聊天紀錄與另存日誌檔是不同選項，參見 [OneComme 官方紀錄說明](https://onecomme.com/docs/feature/comment-log/)。

## 使用條件與限制

目前在 Windows、OneComme 9.1.1 驗證。背景收錄需要 OneComme 正在執行、插件已啟用且收到直播事件；管理頁可以關閉。只計入已人工確認或透過 OneComme 固定頻道連線確認屬於鎖定頻道的直播，不會自動抓取 YouTube 歷史。資料不加密，存於使用者本機 AppData，請不要公開備份或 OBS 金鑰。

這是獨立專案，並非 YouTube 或 OneComme 官方產品。首次公開版本建議先以預發行版本提供測試回饋。

## 開發與測試

版本只維護 VERSION，執行 `node scripts/sync-version.js` 同步其他標籤。發布流程與模組分工見 [維護說明](docs/MAINTENANCE.md)。

使用 Node.js 18 或更新版本，在此目錄執行 `node --test tests/*.test.js`。Windows PowerShell 可先用 `$testFiles = Get-ChildItem tests/*.test.js | Select-Object -ExpandProperty FullName`，再執行 `node --test @testFiles`。不要將日用資料複製進 tests。

`node scripts/package.js` 先做版本、白名單、私人路徑／憑證、語法檢查與三輪測試；全部通過才在 Windows 產生新的 dist/release-版本-時間目錄，包含安裝 ZIP、乾淨原始碼／ZIP、檔案清單、SHA-256 與 VALIDATION.json。只採 scripts/release-files.json 白名單，不複製整個工作目錄，也不刪除既有產物。

選用瀏覽器測試 scripts/check-ui.js 需要 Playwright 與 Edge；可透過 YT_RANK_PLAYWRIGHT 指定既有 Playwright 模組路徑。測試使用隔離資料，不應指向日用資料。
